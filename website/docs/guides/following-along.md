# Follow along and make decisions

Agentville keeps you informed without asking you to watch every step.

## The stage line

When Claude moves into a new stage, the first line of its reply says so, in bold, such as **Stage: Execute**. If you write in another language, the line is written in that language too. A reply that stays in the same stage has no stage line.

If you see something like **Stage: Execute (2nd loop-back)**, a check failed or a reviewer asked for changes, and the work is being done again. That is normal: it is how Agentville fixes problems before you see them.

## The plan summary

When Claude leaves Plan, it shows a short summary: the goal in one sentence, one line per task with its check, and anything skipped or still open. It does not ask for approval. If something looks wrong, reply and say so.

## The final report

Every request ends with a report. It opens with the answer, then says:

- what each task delivered,
- what was checked, and whether it passed,
- what the reviewer said,
- anything still open, including decisions that are yours.

Decisions are written as a choice, such as "the export page has the same problem; tell me whether to fix it". Reply with your choice, and Claude treats it as a new request.
