# Write a good request

You can ask Agentville for anything you would ask Claude. A few habits make the result better.

## Say what you want at the end

Describe the finished thing, not only the topic.

- Less helpful: "Something about our holiday policy."
- More helpful: "A one-page summary of the Acme holiday policy that new staff can read in two minutes."

## Say how you will know it is done

Agentville turns each task into a check. Give it something it can check.

> Draft three subject lines for the Acme spring newsletter. Each must be under 50 characters.

## Say what is out of bounds

If something must not change, say so.

> Tidy the wording of the Acme onboarding guide, but do not change the headings or the order of the sections.

## Let it ask

For anything large or new, add "Ask me anything you need to know first." Agentville will start in Discuss and talk it through with you before it builds anything.

## Say yes to the web only when you mean it

If the answer needs the web, Agentville will ask you first, and name the questions and websites. Say yes only to the sites you trust for the job.
