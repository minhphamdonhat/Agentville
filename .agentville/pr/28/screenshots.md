# Screenshot gallery

This page shows every page of the built site in day and night, at desktop 1280px and mobile 390px: 14 pages and 56 full-page screenshots. Each image is pinned to commit `43e89ca`. The files are in the [screenshots folder](https://github.com/minhphamdonhat/Agentville/tree/ccr-fe3b21c9-3tt218/.agentville/pr/28/screenshots).

The screenshots come from `npm run build`, served locally and captured with Playwright 1.63.0 in Chromium. Animations were paused and requests to other hosts were blocked. Each PNG is quantised to 256 colours at full size and is 222 KB or less.
